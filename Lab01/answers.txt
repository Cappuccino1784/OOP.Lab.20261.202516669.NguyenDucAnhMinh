1. What happens if users choose "Cancel"?
- In Java Swing, choosing Cancel is not the same as choosing Yes or No.
- The dialog returns a special value: JOptionPane.CANCEL_OPTION.
- For example:
  int option = JOptionPane.showConfirmDialog(...);
  if (option == JOptionPane.CANCEL_OPTION) {
      // user clicked Cancel
  }
- If you use YES_NO_OPTION, Cancel is not shown at all. If you want a Cancel button, use YES_NO_CANCEL_OPTION or a custom dialog.

2. How to customize the options to users, e.g. only two options: "Yes" and "No", or "I do" and "I don't"?
- Use JOptionPane.showOptionDialog(...) instead of showConfirmDialog(...).
- You can pass your own button labels in an Object[] array.
- Example:

  Object[] options = {"Yes", "No"};
  int choice = JOptionPane.showOptionDialog(
      null,
      "Do you want to continue?",
      "Confirmation",
      JOptionPane.DEFAULT_OPTION,
      JOptionPane.QUESTION_MESSAGE,
      null,
      options,
      options[0]
  );

- You can also use custom text like:

  Object[] options = {"I do", "I don't"};

- Then check the returned index:

  if (choice == 0) {
      // user clicked "I do"
  } else if (choice == 1) {
      // user clicked "I don't"
  }

- If you want only Yes/No without Cancel, the simpler option is still showConfirmDialog with YES_NO_OPTION. For fully custom labels, use showOptionDialog.

Reference: Java Swing JOptionPane documentation or IDE help (Eclipse/NetBeans) can show the exact method signatures and parameters.
